HOW TO SUBMIT INVOICES IN THIS FOLDER
=====================================

This folder belongs to one Budget Unit. Invoices are picked up automatically
from the folders inside it.


WHERE TO PUT AN INVOICE
-----------------------

  Your own folder (your name)
      The invoice goes to your queue. Only you see it, unless you pass it on.

  Someone else's folder (their name)
      The invoice goes to their queue.

  SHARED
      The invoice goes to this Budget Unit's shared queue, where everyone who
      works this Budget Unit can see it and pick it up.


WHAT IS NOT PICKED UP
---------------------

  Files placed directly in this folder, next to this README, are ignored.
  Put every invoice inside a named folder or the SHARED folder.


WHAT KIND OF FILES
------------------

  PDF files and pictures (JPG, PNG, TIFF, BMP). A picture is turned into a
  PDF for you. Anything else is renamed UNSUPPORTED_FILETYPE_... and left
  where it is, so you can see it was not accepted.


ONE INVOICE OR SEVERAL
----------------------

  A PDF may hold one invoice or several. If it holds several, they are split
  apart for a person to check before they are processed.


QUESTIONS
---------

  Ask the AIM team. This file is recreated if it is deleted, and is left alone
  if it is edited, so a Budget Unit may add its own notes below.
